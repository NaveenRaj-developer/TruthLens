# TruthLens

AI Powered Misinformation Detection Platform

## Features

- Fake News Detection
- Spam Message Detection
- Phishing URL Detection
- User Authentication
- Detection History
- Admin Dashboard
- Machine Learning Models

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Scikit-Learn

## Installation

```bash
pip install -r requirements.txt
python app.py
```
